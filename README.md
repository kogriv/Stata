# Stata

Задачи и заметки по теории вероятностей и статистике. Каждая задача разобрана в README с выводом формул, а рядом лежит скрипт, который считает точный ответ и проверяет его симуляцией: ответ, который не подтверждается симуляцией, сюда не попадает.

Самый подробный разбор — [парадокс Монти Холла](problems/07_monty_hall/): почему одна и та же картинка «две закрытые двери» даёт вероятность выигрыша от 0 до 1 в зависимости от правил ведущего, и что об этом говорил сам Монти Холл. К нему есть [браузерная игра](https://kogriv.github.io/Stata/problems/07_monty_hall/game/) с разными типами ведущего.

## Заметки

## Запуск

Скрипты используют только стандартную библиотеку Python 3.10+:

```
python problems/05_dice_rerolls/solution.py
```

Для перерисовки картинок нужен matplotlib:

```
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt     # Windows; на Linux/macOS: .venv/bin/pip
.venv/Scripts/python notes/pdf_cdf/pdf_cdf.py --plots
```

Симуляции используют фиксированный seed, поэтому вывод воспроизводится.
