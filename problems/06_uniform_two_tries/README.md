# Миллион за число из [0, 1]: забрать или сыграть ещё

## Условие

Есть игровой автомат. При нажатии на кнопку он показывает игроку случайное число из равномерного распределения на интервале [0, 1]. Какое число показал автомат — столько миллионов рублей выигрывает игрок. У игрока есть два возможных действия: он может забрать деньги сразу после первого нажатия кнопки, видя результат, или же сыграть еще раз и забрать деньги после второй попытки.

- Какая стратегия даёт игроку максимальный ожидаемый выигрыш?
- Найти мат. ожидание выигрыша этой стратегии.

(В исходной формулировке — «гарантирует максимальный выигрыш». Гарантировать ничего нельзя: второе нажатие может дать 0. Оптимизировать можно только ожидание.)

## Решение

Второе нажатие **заменяет** первый результат, а не добавляется к нему, и не зависит от него. Поэтому, увидев $X_1 = x$, игрок сравнивает:

- забрать: $x$;
- сыграть ещё: $\mathbb{E}X_2 = \frac12$, независимо от $x$.

Значит, оптимальна пороговая стратегия: забрать, если $X_1 \geq \frac12$, иначе нажать ещё раз.

Ожидаемый выигрыш для произвольного порога $t$:

$$
\mathbb{E}W(t) = \underbrace{\int_t^1 x\,dx}_{\text{забрали } X_1} + \underbrace{t \cdot \tfrac12}_{\text{сыграли ещё}} = \frac{1 - t^2}{2} + \frac{t}{2}.
$$

$\mathbb{E}W'(t) = -t + \frac12 = 0$ при $t = \frac12$, что совпадает с рассуждением выше:

$$
\mathbb{E}W\left(\tfrac12\right) = \frac{1 - \frac14}{2} + \frac14 = \frac38 + \frac28 = \frac58.
$$

**Ответ:** забирать, если выпало не меньше 0,5, иначе играть ещё раз. Ожидаемый выигрыш $\frac58 = 0{,}625$ млн руб. Для сравнения: всегда забирать первое число — 0,5 млн.

## Обобщение: n попыток

Пусть $V_n$ — ожидаемый выигрыш при оптимальной игре с $n$ попытками. Перед последней попыткой брать нечего, $V_1 = \frac12$. С $n$ попытками забираем текущее $x$, если $x \geq V_{n-1}$:

$$
V_n = \mathbb{E}\max(X, V_{n-1}) = \frac{1 + V_{n-1}^2}{2}.
$$

$V_1 = \frac12$, $V_2 = \frac58$, $V_3 = \frac{89}{128} \approx 0{,}695$, … Пороги растут и стремятся к 1: чем больше попыток в запасе, тем привередливее можно быть.

## Типичная ошибка

Рассуждать через $\mathbb{E}[X_2 \mid X_2 > X_1] = \frac{1 + X_1}{2}$. Это ожидание для игры «из двух чисел берём большее», а в этой игре второй результат может оказаться и меньше первого: отказ от $X_1$ необратим. К тому же неравенство $x \geq \frac{1+x}{2}$ даёт $x \geq 1$, а не $x \geq \frac12$, т.е. верный порог через это рассуждение получается только за счёт второй, компенсирующей ошибки.
